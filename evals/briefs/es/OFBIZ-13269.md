# OFBIZ-13269 — Hace falta soporte para un tope máximo de descuento en Promociones

**Tipo:** Task · **Prioridad:** Minor · **Componentes:** order

## Descripción

*Escenario:*

Al configurar un Cart Range Percent Discount para promociones, no parece haber una opción lista para usar que permita fijar un tope máximo de descuento. Por ejemplo, si el negocio quiere ofrecer un 15% de descuento sobre el total del carrito, pero con un límite máximo de descuento de $100 sin importar el valor del carrito, hoy el sistema aplica el porcentaje sobre el total completo del carrito sin techo.

El objetivo principal no es imponer una regla de margen mínimo sobre el precio del producto, sino fijar un límite máximo de descuento sin importar el total del carrito, particularmente para carritos de valor alto.

El requerimiento también considera el caso en que el sistema aplica una sola promoción de carrito a la vez, simplemente para simplificar el escenario.

*Propuesta de solución:*
Extender la entidad ProductPromoAction con un campo maxDiscountAmount y tener en cuenta esa configuración en el motor de promociones para validar el descuento máximo que se le puede dar al cliente.
