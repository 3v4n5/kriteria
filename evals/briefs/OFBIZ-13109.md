# OFBIZ-13109 — Numbering of Customer return invoice does not apply numbering scheme preference

**Tipo:** Bug · **Prioridad:** Major · **Componentes:** accounting

## Descripción

When a customer return invoice are created, the numbering thereof should follow the preferences set for customer invoices in PartyAcctgPreference. Instead, a customer return invoice get a number per the methodology for supplier invoices.

## Criterios de aceptación

_(el ticket no declara criterios de aceptación)_

## Comentarios

### Comentario 1

This is an invalid issue reported as a bug because there is no separate sequence configuration available for customer vs supplier invoices in PartyAcctgPreference entity.

### Comentario 2

Hi [~mridulpathak],

Configuring the *Invoice ID Prefix* (field invoiceIdPrefix) in the accounting preferences separates sales invoice numbering from supplier invoice sequences.

Additionally, enabling the *{{useInvoiceIdForReturns}}* field should ensure that customer sales returns and generated credit notes maintain a continuous, sequential ID in line with sales invoices.
